# Mon Humidor (application autonome)

Même principe que `../mon-sommelier` : PWA installable qui appelle directement l'API Anthropic avec **votre clé** (Réglages). L'humidor est stocké dans le navigateur, avec export/import JSON.
Pas de scan de code-barres ici : les bases publiques ne couvrent pas les cigares.
Réservé aux adultes.
